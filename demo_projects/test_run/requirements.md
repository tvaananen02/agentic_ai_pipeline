PROJECT_NAME: atm-simulator
REQ 1: The system must allow users to insert their card and enter their PIN.
REQ 2: The system must authenticate the user's PIN and allow access to their account if correct.
REQ 3: The system must display the user's current account balance after successful authentication.
REQ 4: The system must allow users to perform transactions such as withdrawals and deposits.
REQ 5: The system must update the user's account balance in real-time after each transaction.
REQ 6: The system must prevent users from withdrawing more than their available balance.
REQ 7: The system must provide an option for users to change their PIN.
REQ 8: The system must provide an option for users to exit the ATM simulation.
